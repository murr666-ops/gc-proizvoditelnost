# Производительность труда: ресторанный контур

Рабочее место исполнительного директора Good Community Ирины Кислицыной в Claude Code. Закрытый репозиторий, только проект: маршрут, журнал решений, правила, заказы на инструменты, замеры и исходные данные на 16.10.2026. Кода моста здесь нет.

## Как начать

1. Открыть Claude Code: claude.ai/code в браузере или вкладка Code в приложении Claude.
2. Выбрать репозиторий `murr666-ops/gc-proizvoditelnost`, ветку `main`.
3. Написать: «Начинаем проект «Производительность труда: ресторанный контур». Я на шаге 0: рамку с ГД обсудили, хочу зафиксировать её в журнале. Задай мне вопросы шага 0 по порядку, по два-три за раз.»

Дальше Claude ведёт по шагам. Полезные фразы: «продолжаем маршрут», «где мы по проекту», «хочу заказать инструмент». Команды: `/marshrut`, `/zhurnal`, `/zakaz-instrumenta`.
