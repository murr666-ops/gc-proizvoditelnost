# Заказ на инструмент

Здесь заказ только оформляется. Собирает инструмент Claude в защищённом репозитории моста по команде Руслана «ставь ZK-NN». Правила — `CLAUDE.md`, раздел 5.

1. Найди в `zhurnal_reshenij.md` решения «перенести в систему» и в `dannye/operacii.csv` операции, которые они закрывают: часы, предприятия, инструмент-замена из `dannye/reestr_instrumentov.csv`. Проверь по `Spravka_o_sistemah.md`, нет ли уже работающей системы: тогда заказ не нужен, нужно включение на объекте.
2. Задай Ирине не больше трёх вопросов из шага 5 маршрута: кто на объекте пользуется ежедневно, как поймём через месяц, что работает, что отключается после включения.
3. Заполни шаблон «Заказ на инструмент» из `Shablony.md`. Добавь раздел «Для сборщика»: какие операции и сколько часов закрывает, на каких объектах, что должно перестать вестись, вопросы, без ответа на которые сборку не начать. Покажи заказ Ирине целиком и спроси «да».
4. После «да»: файл `zakazy/ZK-NN_korotkoe_nazvanie.md` (NN — следующий номер, статус `заказ`), строка в таблице `zakazy/README.md`, решение «заказан инструмент ZK-NN» в журнале с ожидаемым эффектом в часах. Коммит «заказ ZK-NN: оформлен», пуш.
5. Подготовь Ирине короткое сообщение для Руслана, которое она отправит сама: номер заказа, одна строка что это, сколько часов закрывает, желаемый срок. Руслан передаёт в сборку командой «ставь ZK-NN».
6. Статусы `в сборке`, `на проверке`, `включён` обновляет Claude в сессии Руслана. После `включён` помоги Ирине с планом шага 6: сообщение команде, дата выключения старого файла или чата. Подтверждение замером — шаг 7, статус `подтверждён замером`.

Не обещай сроки сборки от себя: срок из реестра инструментов — оценка. Новое пожелание к уже заказанному — новый заказ.
