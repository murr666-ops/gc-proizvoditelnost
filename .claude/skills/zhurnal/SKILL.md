# Журнал: где проект сейчас

1. Прочитай `zhurnal_reshenij.md`, `zakazy/README.md`, `pravila_kontura.md`. Если есть ветки `claude/*` с более свежими коммитами «журнал:», возьми журнал оттуда.
2. Покажи Ирине один экран, без лишних слов:
   - текущий шаг и критерий его готовности (выполнен или нет, чего не хватает);
   - пилотные предприятия и проводники;
   - решений всего, из них по статусам: принято, объявлено, сделано, подтверждено замером;
   - часов освобождено: по оценке решений и по замеру; по предприятиям таблицей, если решений больше пяти;
   - правила контура с датой вступления;
   - заказы на инструменты со статусом и ссылкой на PR;
   - с чего начать следующую беседу.
3. Если Ирина просит одну страницу для Руслана (шаг 7) — собери её в Word по данным журнала: часов освобождено по объектам, куда направлено, что в ФОТ, что не получилось, решения на следующий месяц. Без ФИО и сумм по людям.
4. Ничего в журнал не записывай: этот навык только читает. Изменения — через `/marshrut`.
