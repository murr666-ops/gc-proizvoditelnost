# Хронометраж

Заполненные бланки замера по пилотам: один файл на предприятие и неделю, `NNN_predpriyatie_nedelya_DD.MM.md` или `.xlsx` (бланк — лист «Хронометраж» в `../dannye/Dannye_proekta.xlsx`). Минуты, не часы; без фамилий, только роли. Сводку «замер против оценки» Claude готовит на шаге 2 и 7 и записывает результат в журнал.
