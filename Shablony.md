# Шаблоны проекта

Claude заполняет эти шаблоны по словам Ирины и выдаёт готовый текст или таблицу. Ирина переносит их куда нужно: в журнал решений, в сообщение команде, в заказ на инструмент.

## Журнал решений

Одна строка на решение. Ведёт Ирина (лист «Журнал решений» в `dannye/`); Claude выдаёт готовую строку после каждого решения.

Поля:

- Дата
- Шаг
- Решение (одной фразой)
- Предприятие
- Что меняется (файл, чат, операция)
- Ответственный
- Срок
- Ожидаемый эффект, часов в месяц
- Статус (принято / объявлено / сделано / подтверждено замером)
- Комментарий

## Правило контура

Короткий текст правила, который можно переслать команде без пояснений.

Поля:

- Название правила
- Формулировка (одно предложение: что, где, с какого числа)
- Единственный источник данных
- Что перестаёт вестись (файлы, чаты)
- Кого касается
- Дата вступления
- Кто отвечает за соблюдение
- Как увидим нарушение

## Заказ на инструмент

Передаётся ГД и в сборку (Claude Code, Вертер). Один заказ — один инструмент.

Поля:

- Название инструмента
- Для кого (роль, объекты)
- Что делает (три строки)
- Какие данные использует (iiko, Bitrix24, табель, Prime Hill)
- Что заменяет (файл, чат, операция) и сколько часов в месяц
- Как поймём, что работает (показатель через месяц)
- Кто на объекте пользуется ежедневно
- Что нужно от компании (решение, доступ, шаблон)
- Приоритет (1–5)
- Желаемый срок

## Бланк хронометража недели

Лист на объект на неделю: по строке на операцию, по столбцу на день. Заполняет менеджер смены или управляющий в конце смены; минуты, не часы. Лист «Хронометраж» в `dannye/`.

Поля:

- Операция
- Кто делает
- Пн
- Вт
- Ср
- Чт
- Пт
- Сб
- Вс
- Итого минут за неделю
- Что мешало / что можно убрать

## Сообщение команде

Текст, который Ирина отправляет при объявлении правила или изменения.

Поля:

- Что меняется с какого числа
- Зачем (одна причина, понятная смене)
- Что перестаём делать
- Что делаем вместо этого
- Кто поможет и где спросить
- Что будет через две недели (дата выключения старого)

## Паспорт участка

Карточка на один участок (предприятие и группа операций) для шагов 3–7.

Поля:

- Предприятие
- Участок
- Операции и часы сейчас
- Решения по операциям (убрать / упростить / перенести / оставить)
- Правило контура
- Инструмент (если нужен)
- Проводник на объекте
- Дата включения
- Дата выключения старого
- Часы после замера
- Куда направлено время

## Блок «В журнал решений» (формат ответа Claude после каждого решения)

```
В журнал решений
Дата: …
Шаг: …
Решение: …
Предприятие: …
Что меняется: …
Ответственный: …
Срок: …
Ожидаемый эффект: … часов в месяц (оценка по файлам / по замеру)
Статус: принято
```

## Итог беседы (формат завершения каждой беседы)

```
Итог шага N
Решено: …
Осталось: …
Критерий готовности: выполнен / не выполнен, потому что …
Следующая беседа начинается с: …
```
