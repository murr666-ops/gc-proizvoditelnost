# Справка о системах Good Community (на 16.10.2026)

Что уже работает и чем можно заменить ручные операции. Используется на шагах 3 и 5.

## Отчёт управляющего («пульс ресторана»)

Страница моста по личной ссылке: выручка, чеки, гости, чек, себестоимость, скидки, удаления, часы по дням с января прошлого года из ночного снимка iiko; сравнение с тем же днём недели прошлого года; официанты и блюда за 100 дней. Заменяет ручной план-факт по дням и часть «Главных отчётов».

## Панель снабжения

Страница моста: автозаказ по расходу и остаткам, лимиты, согласованные цены, сигналы приёмки накладных в 09:05, пожелания в чат. Запущена 13.10.2026. Может принять заявки объектов, мониторинг цен, хозтовары, неликвид.

## Дашборд «Комнаты управления»

11 комнат: витрина KPI, задачи Bitrix24, комнаты iiko, Prime Hill, маркетинг, блок «Главный». Основа для светофора объектов.

## Бот «Гуди» (адаптация) и Telegram-бот Вертера

Сотрудник один раз пишет боту и получает роль. Бот умеет присылать материалы, принимать ответы и фото; на нём строятся чек-листы смены, бланк хронометража, журнал инцидентов.

## Вертер (ассистент в Telegram и Claude Team)

Читает диск и чаты Bitrix24, iiko (продажи, склад, техкарты), Google Диск; ставит задачи и встречи в Bitrix24 по подтверждению; расшифровывает записи; делает протоколы, повестки, дайджесты.

## Claude Code (сборка инструментов)

По заказу на инструмент собирает страницы моста, ночные расчёты на сервере Вертера, ботов. Сроки по реестру инструментов: от одной до пяти недель на инструмент, несколько идут параллельно.

## Доступ без Claude Team

Страницы моста открываются по личным ссылкам без пароля; линейный персонал работает через Telegram-бот; обязательства — задачи Bitrix24. Места в Claude Team нужны только руководителям для анализа.

## Как читать лист «Реестр инструментов»

Каждая строка — инструмент, который могут собрать Claude Code и Вертер на имеющихся системах. Поля «Могу создать» и «Недель» — оценка сборщика; «Что нужно от компании» — решение, доступ или шаблон, без которых сборка не начнётся. Статус «Есть» означает, что инструмент уже работает и его нужно только включить на объекте.
